# Fermi Test Prep — reel assets

Static hosting for JEE revision reels so the Instagram Graph API can fetch them.
Meta ingests video by URL only, so these files need a public direct-download link.

Files are served from `raw.githubusercontent.com`, which returns the bytes with
no redirect — Meta's fetcher rejects redirecting or HTML landing-page URLs.

Generated with Manim CE (1080x1920), narration via ElevenLabs.
